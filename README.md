# Student Performance Dataset Analysis

## Project Overview
This project analyzes student performance in mathematics, reading, and writing using Python. It explores how factors such as gender, test preparation, lunch type, and parental education relate to students' scores.

## Objectives
- Explore and understand the dataset.
- Check for missing values and duplicate records.
- Calculate average scores across subjects.
- Compare performance across student groups.
- Visualize important patterns and relationships.
- Generate key insights from the analysis.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Visual Studio Code

## Dataset
The project uses the Students Performance in Exams dataset, containing student demographic and educational information alongside mathematics, reading, and writing scores.

## Project Structure
- `analysis.py` — Python analysis and visualization code.
- `StudentsPerformance.csv` — Original dataset.
- `cleaned_students.csv` — Exported dataset.
- `average_scores.png` — Average subject score chart.
- `visuals/` — Additional charts generated by the analysis.

## Analysis Performed
- Dataset inspection and data-quality checks.
- Subject-wise average score calculation.
- Performance comparison by gender.
- Comparison by test preparation course.
- Analysis by lunch type and parental education.
- Mathematics score distribution.
- Relationships between subject scores.
- Key performance insights.

## How to Run
1. Install Python.
2. Install the required libraries:
   `pip install pandas numpy matplotlib seaborn`
3. Place the dataset in the project folder.
4. Run:
   `python analysis.py`

This project demonstrates beginner-level data analysis skills, including data inspection, grouping and aggregation, correlation analysis, and data visualization. The results can help identify patterns in student performance.
